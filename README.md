# 绝地求生 3D · PUBG 同人网页版

浏览器里的 3D 大逃杀：跳伞、搜刮、跑毒、空投、开车、吃鸡。单个 HTML 文件，Three.js 已内联，无需安装。

**在线试玩：** https://strawberry-eat-mango.github.io/pubg3d/

## 玩法
- 飞机航线随机穿过程序生成的海岛，按 F 跳伞，按住 W 并向下看俯冲
- 9 个城镇（P城、R城、学校、G港、军事基地、机场、狮城、核电站、Y城），可进入的房屋和两层楼
- 8 把枪（M416、AKM、SCAR-L、UMP45、Mini14、Kar98k、S686、空投 AWM），倍镜 / 扩容 / 补偿器
- 一到三级头盔、防弹衣、背包，药品与能量条，破片手榴弹
- 子弹飞行与下坠、部位伤害、护甲减伤
- 7 阶段蓝圈、空投（红烟）、可驾驶吉普车
- 25 / 50 / 80 人对局，4 档电脑难度

## 键位
WASD 移动 · Shift 奔跑 · 空格 跳 · C 蹲 · Z 趴 · V 切换 TPP/FPP
左键 开火 · 右键 瞄准 · R 换弹 · B 射击模式 · 1/2 切枪 · X 收枪 · G 手雷
F 拾取/跳伞/开伞/上下车 · 7 绷带 · 8 急救包 · 9 医疗箱 · 0 饮料/止痛药
Tab 背包 · M 地图 · Esc 暂停

## 构建
源码在 `src/`，运行 `python3 build.py` 生成 `index.html`。
